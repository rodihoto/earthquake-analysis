# Earthquake Analysis

## Overview

This repository contains a Python-based analysis of global earthquake patterns. The project explores seismic activity trends, visualizes spatial distributions, and identifies high-risk regions using techniques such as data cleaning, exploratory analysis, geospatial visualization, and clustering.

## Key Features

- **Data Cleaning**: Handle missing values, remove duplicates, and standardize data formats.
- **Exploratory Data Analysis (EDA)**: Analyze magnitude distribution, depth vs. magnitude relationships, and temporal trends.
- **Geospatial Visualization**: Create interactive maps using Folium to visualize earthquake locations and density heatmaps.
- **Clustering**: Identify regions with high seismic activity using K-Means clustering.
- **Statistical Modeling**: Fit regression models to explore relationships between magnitude and depth.
